KEY IMPROVEMENTS:
- Registry discovery is now fully integrated into main startup flow
- No separate startup scripts needed
- All bridges are discovered consistently and automatically
- Better coverage and reliability
- Integrated with existing factory event monitoring
- Proper timing: registry discovery happens after factory monitoring starts

INTEGRATION POINTS:
- transfers.js: Registry discovery call integrated into start() function
- setup_3dpass_bridges_from_registry.js: Core logic imported and called during startup
- Automatic execution: No manual intervention required
- Error handling: Graceful failure if registry discovery fails
